# lmxxf 时序稳定性实验

这是实验功能，默认关闭；不代表已解决任何游戏的闪烁。保持同帧逐帧推理，不降低原有 NR 强度，不修改模型权重或跳块设置。模型历史与输出平滑独立控制，可以游戏内切换。

## 玩家测试

使用配套的 OptiScaler 和 LmxxfNrRuntime DLL，保留原配置和权重。Ins 菜单中选择 lmxxf，展开 **Experimental → Temporal stability (test)**。第一次开启会分配历史资源和编译两个着色器，切换后等画面稳定再开始比较。

| 快捷按钮 | 模型历史 | 输出平滑 | 用途 |
|---|---:|---:|---|
| A: Baseline | 关 | 0 | 当前无时序基线 |
| B: History | 开 | 0 | 只验证模型历史 |
| C: Smoothing | 关 | 0.25 | 只验证输出平滑 |
| D: Both | 开 | 0.25 | 验证二者组合 |

先比较 A、B：同一地点静止几秒，再做相同速度的转镜头。仍需定位时再试 C、D；不必每项重复长时间采集。不更换 SR、FG、分辨率、NR 强度或其它模型开关。

每项只需记录三件事：**闪烁变化、是否出现黑色拖影、增强细节是否变弱**。特别观察暗色角色/树枝掠过亮背景、新露出的背景及快速转镜头停止之后。降低效果导致“不闪”不能单独算成功。

菜单状态应从 Starting fresh history 变成 Active。若持续 Unavailable，停止比较后续模式并提供 OptiScaler.log；这时没有启用有效的时序对照。状态每 120 次 NR 记录刷新一次。出现明显拖影可直接点 A 恢复基线，无需重启。除首次资源准备外，模式切换不重建模型。

Output smoothing 可在 0–0.5 内调整；先用快捷按钮的 0.25，确有改善再微调。更高可能增加残影或软化细节，不建议一开始就拉满。Save Settings 会保存配置；ini 等价设置如下：

```ini
[DlssNr]
LmxxfModelHistory=false
LmxxfOutputSmoothing=0
```

两项配置通过帧参数传递，不读取 `native-game-flags.txt` 或外部环境变量。这两个键只对 lmxxf 生效。

## 实现与边界

- `TemporalHistory.h` 将前一帧编码域模型输出，按 NGX 运动尺度、jitter 和有效视口映射到当前帧，送入公开 lmxxf 内核已有的历史输入。使用双线性采样；不宣称等价于上游精确量化采样器。
- 只在资源状态/尺寸/格式满足已验证契约时启用。支持零原点有效子矩形、居中 fit 视口及 render/display motion 网格；非零 guide 原点暂时回退无历史。缺失 jitter 或 feature flags 时也回退。
- 运动输入支持双通道和四通道 FP16/FP32（四通道只取 XY）；深度支持 R32、R16 和深度/stencil 的深度平面，包括 R32G8X24。带 mip 链的单层 2D 纹理只读取第 0 层；数组、多重采样和禁止 SRV 的资源仍回退。
- 拒绝越界、非有限运动、深度/原图明显不一致及异常黑色历史；拒绝像素用当前编码输入作为模型历史。深度检查是设备深度启发式，没有相机矩阵重投影，不能证明所有遮挡都被识别。
- 原图一致性阈值当前为编码域每通道 0.08；平滑只作用于与有效历史差异小于 8/255 的模型输出。阈值是实验参数，不是已获得游戏验证的通用最优值。
- 模式/几何/曝光标量改变、reset、评估序号不连续或间隔超过 500 ms 时重新建立历史；consumer 提交后才认可新历史。零输出回退不会被平滑变回旧画面，也不能成为后续有效历史。
- 默认关闭时不分配历史资源。开启后增加三个 float4 工作缓冲；1080p 网络（含 1152 行处理区）约 101.25 MiB，保留至会话/几何重建。没有延迟一帧显示，也没有隔帧推理。
- 未采用新的宿主增强改变量累积、模型裁剪或单纯降低 NR 强度。模型历史本身也可能改变画面，必须与基线一起验收。

运行日志报告请求设置、是否实际启用和帧级历史状态；这些计数不代表每个像素都接受了历史。只有旧局部像素采集时，不能据此声称验证了最终 SR 画面和拖影。

`motionDesc` / `depthDesc` 记录资源尺寸、DXGI 格式号、维度、数组层数、mip 数、采样数和 flags。拒绝原因区分 `motion-format` / `depth-format`、`*-array` / `*-samples` / `*-deny-srv` 等；`historyReset` 说明本帧是否因序号、间隔、模式、运动网格或曝光标量改变而清理历史。持续回退时先检查这些字段，重复切换或重启不会补齐不支持的资源契约。
