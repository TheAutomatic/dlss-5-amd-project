# 鸣潮与伊莫 NR 闪烁调查（2026-10-03）

调查基于 1.9.6.3 的 test12–21 实验系列，尚未完成原生修复。HDR 方向已排除。History、输出平滑和降低 Detail strength 只能作为对照或缓解，不作为根因修复验收。

## 已确认的行为

鸣潮 test17 有效采集中，F6/F7 仍闪，F8 输出原图后不闪。此前重复按 F6 的采集仅采用最后一次有效记录。伊莫 test19–21 角色页及游玩采集均有参考价值；完整帧与局部采集用于离线重放，不能仅凭录制框被角色占据就认定全部数据无效。

相同输入重复完整推理逐位一致；不同真实帧仍包含运动、渲染 jitter 和纹理变化。关闭 adaptive reuse 后网络输出仍可能放大输入变化。复用会增加误差，但关闭复用不足以解决全部闪烁。曝光标量固定的录制也出现问题，不把它描述为整屏统一曝光跳变。

伊莫两帧 8678/8680：按线性 RGB 各通道变化小于 `0.003 + 3%*abs(old)` 筛选，有 952569 个稳定像素；32×32 块超过90%像素稳定且原图均值>0.02的块共194个。输出变化减去原图变化，再按旧输出亮度归一化，移植 exact-reference 的块残差绝对 p95 为14.943196%，稳定像素残差 MAE 为0.005807238。该指标不表示整张输入完全静止。

## 实验边界

- test20 的 C32 attention probability FP16 实验仅部分改善。`CW_PROB_HALF` 和后续 QK/AV/feature/V 精度实验均是构建时选择，默认关闭；未验证的候选不得因已保存源码就成为生产默认。
- 高精度全激活参考、输入去 jitter 及组合均未跨片段稳定解决问题。提高所有精度不等于完整修复。
- 保持 ROI 周围320×320输入不变、仅改变外部区域，中心输出仍变化；说明非局部影响，但不能直接断言某个 ViT 算子错误。
- 恢复原噪声表、完整层和逐步舍入的 AMD reference 仍有波动。它是移植参考链，不能称为独立 NVIDIA/CUDA oracle。
- Q/K 归一化分布探针没有发现所测非零平方和低于保护下限；探针输出与无探针结果逐位一致。该检查只排除所测情形。
- 尚不能确认鸣潮和伊莫同源，不能将两游戏相似表现当作已证实的共同根因。

## 采集与版本

当前源码保留 test17–21 采集和诊断支持，包括完整输入/输出、曝光及 guide 信息、复用状态和可移动 ROI。用户提示通过宿主菜单叠层显示，采集完成状态需要对玩家可见。不同 test 的热键和采集持续时间须以对应宿主提示为准，不混用旧包说明。

test14 的保留 pre-exposure、`preCodec` 日志及 History feedback 修正已覆盖 test12 对应内容。test12 的旧独立测光读回/等待诊断不引回。合并时保留较新的 encoded-mean 测光，并保留主分支命令列表拆分失败保护；旧 decode ratio 限制实验不作为本轮修复。
