# 幻兽帕鲁（Palworld）

用户向兼容说明。代码里不按游戏名判断，下列行为都来自通用判据（格式、几何、曝光是否存在）。

| 项 | 内容 |
|---|---|
| 引擎 / 后端 | UE5；lmxxf、daniel 都能用 |
| 状态 | 2026-09-24 验收通过 |
| 症状（已修） | 某些 DLSS 档位下每帧约 2.5 s |
| 根因（已修） | 拿 Color 的**分配尺寸**去比 NGX **子矩形**。UE5 用非原生档位时两者每帧都不同，于是每帧重建整条 codec 链。现在分配尺寸和分配尺寸比、子矩形和子矩形比（`a129c5f`）。曝光改绑稳定的 1×1 副本，引擎轮换曝光纹理也不会触发重建 |
| 仍有的代价 | `LmxxfFitLarge=true`（2026-09-27 起为默认）时，大于 1920×1080 的 Color 仍然要跑 1080 网络，还要做全分辨率的编解码。09-24 测到：Color 1920×1080 时可玩（eval 间隔 20–40 ms），2258×1271（4K FSR Quality）时约 2 s/帧 |
| 设置建议 | 卡顿时把内部分辨率降到 ≤1080p，或者设 `[DlssNr] LmxxfFitLarge=false`（这样大于 1080p 的输入会被拒绝，NR 不运行） |
