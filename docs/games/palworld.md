# 幻兽帕鲁（Palworld）

用户向兼容说明。代码里不按游戏名判断，下列行为都来自通用判据（格式、几何、曝光是否存在）。

| 项 | 内容 |
|---|---|
| 引擎 / 后端 | UE5；lmxxf、daniel 都能用 |
| 当前状态 | 秒级卡顿 Bug 已修复；截至 2026-09-28，维护者未发现 FitLarge 仍有问题 |
| 症状（已修） | 某些 DLSS 档位下每帧约 2.5 s |
| 根因（已修） | 拿 Color 的**分配尺寸**去比 NGX **子矩形**。UE5 用非原生档位时两者每帧都不同，于是每帧重建整条 codec 链。现在分配尺寸和分配尺寸比、子矩形和子矩形比（`a129c5f`）。曝光改绑稳定的 1×1 副本，引擎轮换曝光纹理也不会触发重建 |
| 设置 | 保持 `[DlssNr] DLSS5_FIT_LARGE=true` 默认值。旧 Bug 期间的秒级帧耗时不代表修复后的性能，不再据此建议降低分辨率或关闭 FitLarge |
| 回归依据 | `a129c5f` 记录了根因和修复；`tests/lmxxf/lmxxf_nr_gpu.cpp` 的 `--subrect` 用分配尺寸大于渲染子矩形的输入，检查连续 PrepareFrame 不增加重建次数 |
