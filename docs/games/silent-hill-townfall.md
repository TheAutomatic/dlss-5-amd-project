# 寂静岭 Townfall（Silent Hill: Townfall）

用户向兼容说明。代码里不按游戏名判断。

| 项 | 内容 |
|---|---|
| 场景 | 超宽屏：3440×1440 显示时，内部渲染约 2024×848 |
| 以前的问题 | lmxxf 的准入要求宽度 ≤1920，超宽输入因此被拒 |
| 现行规则 | 没开 FitLarge 时，按像素预算准入：`w ≤ 2560 && h ≤ 1080 && w*h ≤ 1920*1080`。2024×848 会被接受，缩到 1920×804 跑网络（`80e6809`、`615cdbf`，现在由上游 `native_input_geometry.h` 提供）。开了 FitLarge 则没有这个上限 |
| 验证 | 离线 `--ultrawide` 哈希 `2f4cbf6ce4a39ec7`（最后记录的值） |
| 现状 | 等网友实测，不挡发版 |
